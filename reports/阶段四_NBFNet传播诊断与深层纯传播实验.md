# 阶段四：NBFNet 传播诊断与深层纯传播实验

## 当前结论

截至 2026-07-31，基础 NBFNet 五种子训练和固定种子 44 的核心消融筛选均已完成。基础
模型 holdout Spearman 为 `0.8873 ± 0.0039`，NDCG@K 为 `0.9821 ± 0.0025`，Top-K
收益为 `129.051 ± 0.000`。这些数字说明模型能预测区域价值，但不能证明正确道路拓扑提供
了独立贡献。

固定种子 44 的重新训练结果中，正确有向图、度保持随机重连图、无向图和去边特征模型的
Spearman 都约为 `0.895`，Top-18 收益也相同。固定同一基础 checkpoint 推理时，随机重连
会令 Spearman 从 `0.8947` 降到 `0.8301`，说明已训练权重会使用某种邻接结构；但随机图
重新训练后能恢复，说明当前任务不要求它必须是正确道路拓扑。

## 为什么基础结果不能作为传播成立证据

1. 基础预测头直接拼接 64 维区域统计特征，模型可以沿无传播 MLP 路径预测标签。
2. 深度融合包含传播前第 0 层，每层又保留旧状态，模型可以绕开多跳消息。
3. 候选种子到候选节点的中位距离约 36 跳，候选近似直径中位数约 66 跳，而基础模型只有
   6 层；仅约 4.1% 的候选节点处于 6 跳范围内。
4. 原随机候选切分空间重复严重：holdout 候选平均 93.6% 的节点已经出现在训练候选中，
   最近重叠训练标签即可得到约 `0.9936` 的 Spearman。
5. 十个变体选出完全相同的 Top-18；这些区域共有 9,216 个原始成员位置，却只有 5,791
   个唯一节点，冗余系数为 1.59。单个 Top-18 指标会奖励重复热点副本。
6. 所有首轮模型都在第 100 epoch 取得最佳 checkpoint，最后 10 epoch 验证 Spearman 仍
   在上升，说明优化尚未收敛；但增加 epoch 不能替代更多独立候选数据。

因此当前严格表述是：基础 NBFNet 的预测能力成立，正确道路拓扑和多跳传播贡献未成立。

## 数据切分修正

统一数据集已升级为 `aic.gnn_v2.demand_field_dataset.v2`。候选不再逐个随机分配，而是先将
任意 Jaccard 相似度不低于 `0.50` 的候选连成重叠组，再把整个连通组分配给同一个 split。

- 重叠组数量：521；
- 最大重叠组：12 个候选；
- train / validation / holdout：840 / 180 / 180；
- 保证：跨 split 不存在 Jaccard 相似度不低于 `0.50` 的候选对；
- 新数据摘要：`e9b1bc149a6a94dd744305e41817c3a2b9447cd5e3ba5a17c71fea38db2bf261`。

这仍是同一 H→Y 内的候选泛化，不代替最终未来时间窗口和跨城市测试。

## 最后一轮纯传播实验

本轮是对传播假设的一次直接证伪实验。四个模型都使用 32 层稀疏单跳传播，最大感受野为
32 跳；都切断 64 维区域特征直通，最终读出不含第 0 层，也不构造稠密多跳边。

| 变体 | 残差 | 读出传播层 | 参数量 |
| --- | --- | --- | ---: |
| `propagation_deep` | 无 | 32 | 418,178 |
| `propagation_residual` | 有 | 1～32 的跨层注意力 | 418,209 |
| `propagation_doubling` | 无 | 1、2、4、8、16、32 | 418,183 |
| `propagation_residual_doubling` | 有 | 1、2、4、8、16、32 | 418,183 |

四组参数量几乎一致。所谓“倍增”在本轮指按指数尺度读取已经通过稀疏道路边传播的状态，
不是物化 2 跳、4 跳的全连接边，因此不会产生多跳边数量爆炸。残差组允许层内保留旧状态，
但最终预测头仍不能直接读取原始区域特征或第 0 层。

训练固定种子 44 做首轮筛选，最大 300 epoch、验证 Spearman 选 checkpoint、耐心值 60，
holdout 从不参与选择。输出同时报告 Spearman、固定 K=5/10/18 的 NDCG 与真实收益、唯一
节点数和成员冗余。只有单种子出现明确传播信号后，才扩展五种子和更多独立数据。

本机是唯一代码与文档主机；服务器只从 `main` 快进同步代码并提供 CUDA 算力，不在服务器
编辑、提交或整理仓库。后台训练命令为：

```bash
nohup env PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True \
  .venv-gnn/bin/python scripts/run_nbfnet_ablation.py \
  --mode screening \
  --variants propagation_deep,propagation_residual,propagation_doubling,propagation_residual_doubling \
  --output-root results/gnn_v2/nbfnet_propagation/screening \
  --layers 32 --prototype-batch-size 4 \
  --max-epochs 300 --patience 60 \
  > results/gnn_v2/nbfnet_propagation/screening/launcher.log 2>&1 < /dev/null &
```

## 额外口径修正

`shuffled_od` 不再简单置换终点原型。新实现用半周期保测度耦合打乱起终点配对，同时严格
保持加权起点边际和终点边际，避免把全局终点分布变化误认为 OD 配对贡献。

## 判定规则

- 若严格纯传播在空间隔离 split 上仍能取得稳定排序，并且倍增或残差带来一致增益，则扩展
  独立候选、时间窗口、尺度和城市，再做正式五种子拓扑消融。
- 若切断直通、匹配感受野、延长训练后仍明显落后 MLP/频率，或随机拓扑仍能恢复同等效果，
  则应接受“传播对当前区域价值任务没有必要，或当前监督无法识别传播”的结论，不再继续
  堆叠传播结构。
