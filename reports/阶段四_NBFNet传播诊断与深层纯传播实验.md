# 阶段四：NBFNet 传播诊断与深层纯传播实验

## 当前结论

截至 2026-07-31，基础 NBFNet 五种子训练和固定种子 44 的核心消融筛选均已完成。基础
模型 holdout Spearman 为 `0.8873 ± 0.0039`，NDCG@K 为 `0.9821 ± 0.0025`，Top-K
收益为 `129.051 ± 0.000`。这些数字说明模型能预测区域价值，但不能证明正确道路拓扑提供
了独立贡献。

固定种子 44 的重新训练结果中，正确有向图、度保持随机重连图、无向图和去边特征模型的
Spearman 都约为 `0.895`，Top-18 收益也相同。固定同一基础 checkpoint 推理时，随机重连
会令 Spearman 从 `0.8947` 降到 `0.8301`，说明已训练权重会使用某种邻接结构；但随机图
重新训练后能恢复，说明当前任务不要求它必须是正确道路拓扑。

空间隔离新 split 上的四组 32 层纯传播筛选现已全部完成，实验 ID 为
`38bfa5d15809b383`，四组均成功、无失败。四组 holdout Spearman 为 `0.9513～0.9594`。
由于这些模型既不能读取 64 维区域特征，也不能读取第 0 层，这轮结果正式支持：**经过道路
边传播的历史 OD 表示本身足以强力预测当前 H→Y 任务中的候选区域价值**。它否定了“切断
捷径后纯传播必然无法学习”的担忧，但仍不能证明正确道路拓扑不可替代，也不能与旧 split
上的基础 NBFNet/MLP 数字直接比较。

## 为什么基础结果不能作为传播成立证据

1. 基础预测头直接拼接 64 维区域统计特征，模型可以沿无传播 MLP 路径预测标签。
2. 深度融合包含传播前第 0 层，每层又保留旧状态，模型可以绕开多跳消息。
3. 候选种子到候选节点的中位距离约 36 跳，候选近似直径中位数约 66 跳，而基础模型只有
   6 层；仅约 4.1% 的候选节点处于 6 跳范围内。
4. 原随机候选切分空间重复严重：holdout 候选平均 93.6% 的节点已经出现在训练候选中，
   最近重叠训练标签即可得到约 `0.9936` 的 Spearman。
5. 十个变体选出完全相同的 Top-18；这些区域共有 9,216 个原始成员位置，却只有 5,791
   个唯一节点，冗余系数为 1.59。单个 Top-18 指标会奖励重复热点副本。
6. 所有首轮模型都在第 100 epoch 取得最佳 checkpoint，最后 10 epoch 验证 Spearman 仍
   在上升，说明优化尚未收敛；但增加 epoch 不能替代更多独立候选数据。

因此对基础六层结果本身的严格表述是：预测能力成立，正确道路拓扑和多跳传播贡献未成立。

本轮是对传播假设的一次直接证伪实验。四个模型都使用 32 层稀疏单跳传播，最大感受野为
32 跳；都切断 64 维区域特征直通，最终读出不含第 0 层，也不构造稠密多跳边。

| 变体 | 残差 | 读出传播层 | 参数量 |
| --- | --- | --- | ---: |
| `propagation_deep` | 无 | 32 | 418,178 |

| `propagation_doubling` | 无 | 1、2、4、8、16、32 | 418,183 |

训练固定种子 44 做首轮筛选，最大 300 epoch、验证 Spearman 选 checkpoint、耐心值 60，

### 优化过程观察：深层纯传播跨过长平台期

第一组在前 22 epoch 呈现近乎完全静止的假象：训练损失约为 `0.5245`，验证损失约为
`0.5482`，validation Spearman 稳定在约 `-0.88`。第 23 epoch，validation Spearman
突然翻转为 `0.9334`，验证损失同时降至 `0.5391`。此后排序没有退回随机状态；到第 36
epoch，训练损失已经降至 `0.4071`，验证损失降至 `0.4299`，validation Spearman 连续
保持在约 `0.9305`。

这不是“需求每个 epoch 向外多传播一跳，直到第 23 epoch 才到达候选中部”。每次前向计算
都会完整执行全部 32 层传播；epoch 只重复参数优化，不改变单次前向的传播跳数。因此平台期
属于优化过程，而不是空间传播波前尚未到达。

代码与日志共同给出一个更具体的高置信解释：训练没有学习率 warmup 或 epoch 23 的显式
开关，但启用了 FP16 autocast 和默认 `GradScaler`。每轮先在更新前计算并记录 train loss，
然后执行 `unscale_ → clip_grad_norm_ → scaler.step → scaler.update`，最后在更新后计算
validation。若缩放后的梯度含非有限值，`GradScaler` 会跳过 optimizer step 并降低 scale。
四个结构在 epoch 1～22 的验证损失几乎逐位不变，epoch 23 的 train loss 仍保持平台值，
但同轮更新后的 validation 首次变化；四组又都在完全相同的 epoch 23 同步发生。这组现象与
“前 22 次 optimizer step 因 AMP 溢出被跳过，第 23 次才首次成功更新”高度一致。

原筛选日志没有保存每轮 `GradScaler.get_scale()`、非有限梯度计数或
`optimizer_step_skipped`，当时只能给出高置信诊断。随后 B1/B2 已补齐直接观测：B1 默认
scale `65536` 的前 22 次 step 全部跳过；B2 从 scale `1` 开始，降至 `0.015625` 后在
epoch 7 首次有效更新。`65536 → 0.015625` 恰好需要 22 次减半，因此旧平台期现已确定为
FP16 backward 溢出触发 GradScaler 跳步，不是“传播等待若干 epoch 才到达中部”。

B3（BF16）和 B4（CUDA FP32）随后完成，均从 epoch 1 开始记录为 80 次未跳过的
optimizer step；但两组的裁剪前梯度范数每轮都是 `inf`，裁剪后均为 `0.0`，参数差范数则为
近乎恒定的 `8.70e-6`。这与 AdamW 的解耦 weight decay 造成的微小参数移动相符，不能作为
模型已获得有效反向学习信号的证据。B3 的 validation Spearman 仅从 epoch 0 的 `0.9459` 波动
到历史最高 `0.9464`，B4 则从 `0.9459` 到 `0.9459`；二者 holdout 均约 `0.9602`，仍是 seed 43
的初始化排序轴。故 FP16 scale 是造成“前 22 轮完全不更新”的直接原因，但不是全部根因：即使
移除 AMP scale，深层旧目标仍产生非有限梯度并被裁剪为零。

### 重复 seed 43：一次有效更新导致的灾难性恶化

重复实验的 seed 43 与上述“前 22 轮没有可见更新”现象相同，但其初始排序恰好为正：epoch 1
validation Spearman 为 `0.9458`，并在 epoch 1～22 基本不变。它不是一轮内学得高分，而是与
seed 44 初始约 `-0.9457` 几乎反号的随机读出方向。此后 validation loss 连续下降、Spearman
缓慢降至约 `0.9384`；但在 epoch 59 出现单次突变：

| epoch | train loss（更新前） | validation Huber | validation rank | validation total | validation Spearman |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 58 | 0.4054 | 0.3018 | 0.6009 | 0.4219 | 0.9384 |
| 59 | 0.4045 | 0.6841 | 0.6266 | 0.8094 | 0.8004 |
| 60 | 0.7981 | 0.6931 | 0.6260 | 0.8183 | 0.7988 |
| 61 | 0.8081 | 0.6940 | 0.6257 | 0.8191 | 0.7968 |

代码在每轮先记录更新前的 train loss、再执行 optimizer step、最后计算 validation。因此 epoch 59
仍正常的 train loss 与同轮翻倍的 validation loss 共同证明：第 59 次有效更新已经把参数推入
更坏区域；epoch 60 起 train loss 同步恶化，排除验证抽样噪声或单次评测偶然性。总损失增加
几乎全部来自 Huber（`0.3018 → 0.6841`），但 pairwise loss 也变坏，Spearman 随之下降 `0.1380`。

这与“Huber 和 Spearman 略有权衡”的平滑现象不同，是数值/优化不稳定的直接证据。由于没有
记录 scaler、梯度范数、参数差和 Adam 状态，不能在事后把它唯一归因于 FP16；合理候选包括
边界有限但方向错误的 Adam 更新、深层高曲率和混合精度舍入。若 GradScaler 当轮检测到非有限
梯度，它会跳过 step 且不应造成该跳变，因此这更像一次未被跳过的有害更新。seed 43 最终在
epoch 61 早停，best checkpoint 是 epoch 1，holdout Spearman `0.9600`；按新协议它应标为
`initialization_dominant` 的未训练基线，而不能作为已训练模型的正面证据。

排序翻转本身则更像读出方向穿过零点。四组更新前已经存在稳定但方向相反的候选次序，
validation Spearman 为 `-0.88～-0.95`，ranking loss 约为随机二分类基准 `log(2)`；第一次
有效更新只让总验证损失小幅下降，却使主导排序的系数改变符号，于是 Spearman 可以从强负
相关瞬间变成强正相关。此后训练和验证损失连续下降，而排序基本稳定，说明后续优化主要在
校准收益幅度，不是在第 23 轮才突然形成全部空间结构。

该变体不能读取 64 维区域特征，也不能读取第 0 层；其候选间差异只能来自历史 OD 状态在
道路边上传播 32 层后的区域池化。因此该过程支持：深层传播后的历史需求场包含较强的
区域价值排序信号。它尚不能证明正确道路拓扑不可替代，也不能证明已经超过基础 NBFNet 或
MLP。

必须特别区分数据口径：已有基础 NBFNet 和 MLP 结果使用旧数据摘要 `ffcb11cc...`，本轮
纯传播使用重叠组隔离后的新数据摘要 `e9b1bc14...`。旧结果的 holdout Spearman 与本轮结果
不可直接作增益比较；本轮正式结论只在四个纯传播结构之间比较，并把同新 split 基线、随机
拓扑纯传播、重复种子和未来时间窗口留作后续独立验证。

### 残差纯传播在同一第 23 epoch 复现排序翻转

第二组 `propagation_residual / seed 44` 复现了几乎相同的平台与突破过程。第 1～22
epoch，训练损失约为 `0.5287`，验证损失保持 `0.552725`，validation Spearman 固定为
`-0.9323`。第 23 epoch，validation Spearman 翻转为 `0.8056`，验证损失降至
`0.541740`；第 24 epoch 已升至 `0.9247`，第 31 epoch 达到 `0.9335`。到第 54 epoch，
最终最佳 validation Spearman 为 `0.9342`；第 60 epoch 的训练/验证损失已继续降至
`0.257806 / 0.261100`，排序仍稳定在约 `0.9342`。

四个纯传播结构最终都在完全相同的第 23 epoch 跨过强负相关平台：`propagation_deep`、
`propagation_doubling`、`propagation_residual`、`propagation_residual_doubling` 首次转正的
validation Spearman 分别为 `0.9334 / 0.8258 / 0.8056 / 0.7914`。随后验证排序稳定、训练和
验证损失持续下降。这显著降低了单点日志异常或偶然抖动的可能性，并加强了“切断区域特征
和第 0 层后，传播表示仍包含强区域排序信号”的证据；但 22 个静止 epoch 不应计作有效
优化轮数。特别是 `propagation_deep` 的最佳 epoch 23 很可能只是第一次有效参数更新，因而
后续仍必须用重复种子检验这种初始化方向翻转是否稳定。

## 四组最终结果

模型结构必须按 validation 选择，holdout 不参与结构选择。四组完整结果如下；NDCG 与收益
按固定 `K=5/10/18` 列出。

| 变体 | 最佳 epoch | Validation Spearman | Holdout Spearman | Holdout NDCG@5/10/18 | Holdout 收益@5/10/18 |
| --- | ---: | ---: | ---: | --- | --- |
| `propagation_deep` | 23 | 0.9334 | 0.9513 | 0.9547 / 0.9518 / 0.9782 | 170.043 / 153.225 / 142.332 |
| `propagation_residual` | 54 | 0.9342 | 0.9589 | 0.9331 / 0.9719 / 0.9698 | 163.418 / 158.022 / 139.802 |
| `propagation_doubling` | 35 | **0.9400** | 0.9569 | **0.9720 / 0.9821 / 0.9882** | **171.922 / 158.022 / 142.332** |
| `propagation_residual_doubling` | 50 | 0.9393 | **0.9594** | 0.9676 / 0.9775 / 0.9847 | 171.922 / 158.022 / 142.332 |

validation 上，倍增读出相对末层纯传播的 Spearman 提高 `0.0066`，且固定 K 的排名质量整体
更好，因此本轮按预定规则选择 `propagation_doubling` 作为后续正式扩展结构。残差单独只把
validation Spearman 提高 `0.0008`；组合模型也没有超过倍增模型。组合模型 holdout 最高的
`0.9594` 只能作为描述性结果，不能反向用于模型选择。

所选倍增模型在 holdout 的 NDCG@5/10/18 为 `0.9720 / 0.9821 / 0.9882`，平均真实收益为
`171.922 / 158.022 / 142.332`；对应 Oracle 为 `176.847 / 160.193 / 143.298`。但其成员冗余
系数仍为 `1.744 / 1.786 / 1.750`，说明高价值候选仍集中在相互重叠的热点区域，固定 K 排名
不能替代后续的非重叠固定预算集合选择。

| 变体 | 训练 epoch | 训练时间 | 峰值已分配显存 |
| --- | ---: | ---: | ---: |
| `propagation_deep` | 83 | 65.8 分钟 | 7.11 GiB |
| `propagation_residual` | 114 | 116.3 分钟 | 17.25 GiB |

残差全层读出没有形成稳定的 validation 增益，却显著增加训练时间和显存；因此当前没有继续
采用全层残差读出的依据。倍增读出以较低额外成本获得了本轮最稳定的 validation 改善。

## 额外口径修正

`shuffled_od` 不再简单置换终点原型。新实现用半周期保测度耦合打乱起终点配对，同时严格
保持加权起点边际和终点边际，避免把全局终点分布变化误认为 OD 配对贡献。

## 同口径 Proxy 对照

第一版确定性 midpoint Proxy 已在相同新 split 上完成本机 CPU 评测。它只使用历史窗口
34,328 条 OD 和静态图构造固定扩散及中点风险，不读取标签窗口。

| 模型 | Holdout Spearman | NDCG@5/10/18 | 收益@5/10/18 |
| --- | ---: | --- | --- |
| MLP 五种子均值 | 0.8696 ± 0.0197 | 0.9425 / 0.9724 / 0.9593 | 164.701 / 157.000 / 136.841 |
| midpoint Proxy | 0.8918 | 0.9645 / 0.9454 / 0.9830 | 170.043 / 149.592 / 142.332 |
| `propagation_doubling` seed 44 | **0.9569** | **0.9720 / 0.9821 / 0.9882** | **171.922 / 158.022 / 142.332** |

纯传播的全局 Spearman 比 Proxy 高 `0.0651`，K=5、K=10 收益分别高 `1.879`、`8.431`。
但两者 Top-18 候选集合完全相同，只是集合内排序不同，因此 Top-18 平均收益也完全相同；
K=5 和 K=10 的候选交集分别为 4 和 7。结论应限定为纯传播改善全局排序及较小 K 的选择，
不能声称它已在当前 K=18 固定候选预算上超过简单 Proxy。

## 正式判定与边界

1. 纯传播压力测试通过：传播后的历史 OD 表示对当前区域价值标签具有强排序能力。
2. 本轮按 validation 选择倍增读出；残差和残差加倍增没有证明额外结构价值。
3. 旧协议五种子已经完成，但 holdout Spearman 为 `0.8860 ± 0.1149`，最差 seed 45 仅为
   `0.6943`；它证明当前协议不稳定，而不是提供多种子稳定性结论。
4. 当前 holdout 隔离的是候选重叠组，不是冻结未来时间窗口，也不是跨城市泛化。
5. 新 split 同口径 MLP 和 midpoint Proxy 已完成；纯传播的 Spearman 与 K=5/10 收益更高，
   但 Top-18 集合与 Proxy 完全相同。旧协议重复种子已经完成但不稳定，且基础 NBFNet、
   端点密度和随机拓扑纯传播仍缺失，因此不能声称正确道路拓扑已经被证明必要。
6. Top-K 候选仍高度重叠；进入固定预算部署前，必须单独解决非重叠集合选择和 shortcut
   预算，并执行精确在线配对评测。

因此，本轮最后一次直接证伪已经得到正结果：不再接受“纯传播在当前监督下完全无法工作”
这一判断。研究主线可以继续，但下一阶段应扩展其余同口径基线、随机拓扑对照、重复种子和真正
未来窗口，而不是继续堆叠新的传播结构。

## 已冻结的后续顺序

旧协议五种子已经完成。seed 42 的最佳 validation Spearman 仅为 `0.7640`，holdout 为
`0.8622`；seed 43 在前 22 轮几乎没有数值变化，却从 epoch 1 起保持约 `0.9458`
的 validation Spearman，与 seed 44 初始约 `-0.9457` 几乎反号。seed 43 真正开始更新后，
validation loss 从约 `0.5424` 下降，Spearman 反而小幅下降。这不是单纯的过拟合，而是随机
读出方向、AMP 跳步嫌疑以及 Huber 数值回归与 Spearman 排序选择不一致共同构成的异常。

五种子 holdout Spearman 为 `0.8860 ± 0.1149`，NDCG@18 为 `0.8656 ± 0.2594`，Top-18
收益为 `129.138 ± 26.705`。seed 43 的最佳 checkpoint 位于 epoch 1，应继续标为
`initialization_dominant`；seed 45 则在全局 Spearman 和 Top-K 上同时失败。完整统一摘要见

### 零训练基线揭示的潜在一维排序轴

本机 CUDA 已完成独立的 Z0/Z1/Z2 评测。Z0 不复用现有 `fixed_diffusion` 变体中的随机编码器
和预测头，而是直接把历史起点与终点需求作为标量场，在有向道路图上分别正向和反向做固定
均值扩散，并在 `1/2/4/8/16/32` 跳等权读出。Z0 完全不含可学习参数，validation / holdout
Spearman 已达 `0.9411 / 0.9356`；holdout NDCG@5/10/18 为
`0.9307 / 0.9642 / 0.9745`。

Z1 保留随机初始化的 `propagation_doubling`，但不执行 backward 或 optimizer step。五种子
原始 holdout Spearman 为 `-0.9284 / +0.9601 / -0.9572 / -0.9569 / +0.8855`，绝对值均值
`0.9376`。seed 间排序相关性大多接近 `+1` 或 `-1`，直接证明随机网络不是生成五套不同的
候选结构，而是把同一强潜在排序轴投影为随机正负方向。Z2 只用 train split 决定全局符号，
五种子 holdout Spearman 为 `0.9376 ± 0.0285`，未使用 validation 或 holdout 定向。

这一结果解释了 seed 43 为何在首次有效 optimizer step 前已经得到高分，也改变了后续模型
设计。训练模型不能再以“翻转随机读出符号”作为贡献；正式 rank-first 候选应以 Z0 为固定
正向先验并学习排序残差，epoch 0 从 Z0 出发。seed 46 的 Z2 虽有 `0.8855` Spearman，
NDCG@5/10/18 却只有 `0.6467 / 0.6512 / 0.6658`，说明学习部分仍有明确任务：稳定修正头部
候选，而不是重复拟合已经存在的全局空间梯度。完整结果、逐候选预测和地图见
`results/gnn_v2/nbfnet_propagation/train_free_baselines/`。

因此后续顺序调整为“完成平台期与 optimizer 更新诊断 → 以 Z0 为固定先验的 rank-first
排序残差 → 与完整 rank-first NBFNet 做 validation 对照 → 新协议五种子 → 最终协议下关键
消融”。保留现有数据、split 和双向传播主线；消融不取消，但在学习模型稳定超过 Z0 前不启动。
完整参数、阶段门和复跑规则见 `reports/阶段四_GNN第二版实施计划.md` 的“纯传播稳定性、训练
目标诊断、消融与调参追加计划”。
