## 编译

已在本机使用 XeLaTeX 与 BibTeX 成功生成单栏和双栏两版 PDF。
需要重新生成时，可在本目录运行：

```bash
xelatex main.tex
bibtex main
xelatex main.tex
xelatex main.tex
```

或者：

```bash
latexmk -xelatex -bibtex main.tex
latexmk -xelatex -bibtex main_twocolumn.tex
```

正文采用 `ctexart`，必须使用 XeLaTeX 或 LuaLaTeX，不建议使用 pdfLaTeX。

## 冻结口径

- 底层索引明确写成已有 CRP/Graph Separator 式边界覆盖图，不主张原创压缩结构；
- 论文差异化核心是选择性区域物化、精确区域收益、无历史路径输入、时空隔离和严格不重叠部署；
- Z0 是面向本任务的无参数双向多尺度需求传播组合，不主张新的基础扩散算子；
- G4 的论文名称为 BRIDGE，是受约束的神经排序残差与实证贡献，不主张新的通用 GNN、残差结构或排序损失；
- BRIDGE 稳定改善全局 Spearman，但不写成全面改善 Top-K 或在线收益；
- BRIDGE-B 将 Top-K 收益、shortcut 预算与区域冲突纳入训练；三种子稳定保住全局/头部并降低
  shortcut，两城在线展开与 Z0 的差异均不足 3%，其中 Porto 小幅改善；
- 查询尺度分层表明中长距离/高搜索工作量查询更能摊薄索引接入成本；短步行、骑行式负载是明确
  适用边界，但不能把两城差异写成交通方式的因果证明；
- 全部表格数字来自 `reports/最终研究成果与论文结论.md` 的冻结结果。
