## 2. 最终核心数字

| 城市 | 方法 | Holdout Spearman | Future Spearman |
| --- | --- | ---: | ---: |
| Porto | Z0 | 0.935603 | 0.944656 |
| Porto | G4 三种子 | **0.945902 ± 0.001699** | **0.956598 ± 0.001580** |
| Chicago | Z0 | 0.941135 | 0.897509 |
| Chicago | G4 三种子 | **0.946787 ± 0.001144** | **0.925712 ± 0.000866** |

六个种子的 holdout 与 future Spearman 相对 Z0 均为正。但 Chicago holdout NDCG@18 从 Z0 的
`0.922494` 降到 G4 的 `0.866699 ± 0.033993`，所以不能把全局排序提升写成全面头部提升。

Porto K=18 的 Z0 当前/未来展开节点变化为 `-17.46% / -17.76%`，G4 为
`-17.59% / -17.80%`；G4 增量很小且 shortcuts 更多。Chicago Z0 为
`-21.47% / -21.92%`，G4 为 `-19.62% / -20.28%`；Z0 更强。Chicago 干净复跑中所有 42 组的
平均墙钟耗时均未加速，说明当前 Python shortcut/端点接入开销会抵消展开节点减少。

## 4. 当前主线代码地图

### 精确查询与压缩

- `src/shortest_path.py`：原图最短路；
- `src/compression_index.py`：区域 shortcut 与物化压缩图；
- `src/indexed_query.py`：端点局部接入与精确压缩查询；
- `scripts/verify_materialized_queries.py`：逐查询配对正确性与性能。

### 候选、标签与数据隔离

- `src/region_candidates.py`：全图固定随机连通候选；
- `src/region_labels.py`：单区域精确收益；
- `src/demand_field_data.py`：H/Y、需求原型和重叠组 split；
- `scripts/evaluate_z0_future_window.py`：冻结未来窗口；
- `scripts/evaluate_non_overlapping_selection.py`：集合选择。

### 传播与学习

- `src/demand_field_nbfnet.py`：双向传播、G0～G3 结构与 doubling 读出；
- `scripts/train_demand_field_nbfnet.py`：CUDA 训练、soft Spearman、快照 catalog；
- `scripts/diagnose_demand_field_gradients.py`：深层梯度解剖；
- `scripts/select_g4_validation_peaks.py`：validation-only 峰值冻结；
- `scripts/export_g4_frozen_predictions.py`：冻结 checkpoint 的 holdout/future 推理；
- `scripts/aggregate_g4_frozen_evaluations.py`：跨服务器、跨种子汇总。

### 最终在线闭环

- `src/region_selection.py`：严格非重叠选择；
- `scripts/evaluate_multi_region_online.py`：两城 K=5/10/18、Y/F 在线配对。

## 6. 为什么研究可以收口

研究问题的关键证据已经完整：

1. 真实道路拓扑贡献在两城的度保持重连消融中复现；
2. Z0 的空间 holdout、未来窗口和精确在线收益均完成；
3. 神经残差的数值稳定、损失目标、重复种子和跨城市结果均完成；
4. G4 的正结果与 Top-K/系统负边界都已锁定；
5. 所有方法最终都进入相同严格非重叠和精确查询闭环。

继续扫描学习率、scheduler、深度或预训练只会扩大研究者自由度，不再是完成论文所必需。后续工作
是方法图、结果图、相关工作、论文排版、导师审核和比赛材料；第三城市只作为冲击更高档期刊的
可选增强。
